# Daft Mover

**Supports Unreal Engine 5.5**

**! 5.5 is not currently stable, use at your own peril. For stable version, use the main branch !**

Custom implementation ontop of Mover.

Worth noting that this plugin was originally made when Mover was still on main, so needless to say since this time there has been some extremely breaking API changes, if you used this plugin previously and are now upgrading to newer versions - expect that almost everything will be broken and you have a lot of work to do.
